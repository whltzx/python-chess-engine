# Python Chess Engine

A chess engine written in Python using Pygame.

The project is being developed incrementally, starting with the core game logic and graphical interface and gradually moving towards move generation and chess-playing algorithms.

## Current status

The graphical interface and basic game functionality are implemented. The project currently supports:

- Chess board and piece rendering
- Player movement
- Move handling
- Move history
- Undoing moves

The current stage of development focuses on generating valid chess moves.

## Roadmap

The project will eventually cover:

- Complete chess move generation
- Check and checkmate detection
- Castling and en passant
- Position evaluation
- Minimax search
- Alpha-beta pruning
- Chess-playing AI

## Development

The project is being built in Python with Pygame. Git and GitHub are used for version control and development history.
